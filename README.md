# 市外局番マップ (Area Code Map)

[日本語版 / Japanese](README.ja.md)

A static web app for Japanese landline numbers. Type the first few digits and the matching area
is zoomed into and colored on a pannable/zoomable map, with the MA (message area) names and
municipalities listed as text.

- `0` → nothing happens, `09` → all 09x areas, `097` → Oita + Beppu + other 097x areas,
  `0975` → Oita only, `0977` → Beppu only.
- Overlapping area codes and exchange prefixes can produce multiple matches: `0839` includes
  Yamaguchi and Mine, while `08397` narrows to Yamaguchi; `01548` includes Kushiro and Teshikaga.
- Mobile numbers (090/080/070), 0120 and other non-geographic numbers show an error with guidance.
- The phone number is part of the URL path (e.g. `/0977`).
- On-page keypad (0-9, backspace, clear): no virtual keyboard appears on mobile.
- No server side: everything is static files. Map: [MapLibre GL JS](https://maplibre.org/) with
  GeoJSON only (no map tiles).

## Requirements

- Node.js 22.12+ and [Yarn](https://yarnpkg.com/) 4 (via Corepack: `corepack enable`)

## Install and run

```sh
yarn install
yarn dev        # development server
yarn test       # unit tests
yarn build      # type-check + production build into dist/
yarn preview    # serve dist/ locally
```

## Deployment

`dist/` is fully static. Because the URL path carries the number, the host must serve `index.html`
for unknown paths. `yarn build` also writes `dist/404.html` (a copy of `index.html`), which makes
GitHub Pages work. For other hosts add a rewrite rule (`/* → /index.html`).

Environment variables (see `.env`):

| Variable | Purpose |
| --- | --- |
| `VITE_SITE_URL` | Absolute site URL with trailing slash, used for canonical/OGP URLs and generated `sitemap.xml`/`robots.txt` |
| `VITE_BASE` | Base path when deployed in a sub-directory (e.g. `/areacode-map/`) |

## Updating data

Runtime data is JSON in `public/data/`:

- `areas.json`: area code, exchange prefixes, MA name, color and municipalities (JIS codes)
- `municipalities.topo.json`: boundaries (TopoJSON)

They are generated by `scripts/build-data.mjs` from `data/source/`:

```sh
# 1. Get the latest MIC PDF and convert it to text
curl -o soumu.pdf https://www.soumu.go.jp/main_content/000141817.pdf
pdftotext -layout soumu.pdf data/source/soumu-000141817.txt
# 2. (optional) refresh libphonenumber names
curl -o data/source/libphonenumber-ja-81.txt \
  https://raw.githubusercontent.com/google/libphonenumber/master/resources/geocoding/ja/81.txt
# 3. Rebuild
yarn data:build
```

The script prints unresolved/uncovered municipalities. Icons and OGP image are generated with
`yarn assets:build` (Font Awesome phone icon).

## Limitations

- MA names are derived heuristically (libphonenumber names, otherwise municipality names).
- Where an exchange range splits a municipality, the whole municipality is colored (lighter shade
  = partially covered). Boundaries are approximate.
- Boundaries are from 2021-01-01 (MLIT N03); later municipal mergers are not reflected.
- Not an official source. Check the MIC allocation list for authoritative information.
